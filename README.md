Мой личный адаптивный сайт-визитка с прайс-листом услуг, списком навыков и формой обратной связи. Проект полностью готов к размещению на **GitHub Pages** и оптимизирован под мобильные устройства.

🔗 **Живой пример сайта:** [fenix153.github.io/BioFenix/](https://github.io)

---

## 🚀 Функционал проекта

* 📱 **Полная адаптивность** — сайт отлично выглядит на ПК, планшетах и смартфонах.
* 🎧 **Встроенный плеер** — фоновое воспроизведение трека (6arelyhuman — Faster n Harder) с кастомным интерфейсом.
* 💰 **Интерактивный прайс-лист** — наглядные карточки с ценами на плагины Minecraft, разработку сайтов и настройку Discord-серверов.
* 💬 **Прямая интеграция** — кнопки быстрого перехода в Discord-сообщество и личные сообщения.

---

## 🛠️ Технологический стек

* **HTML5** — семантическая структура и разметка страницы.
* **CSS3** — кастомные стили, анимации, Flexbox/Grid сетки для адаптивности.
* **JavaScript** — логика аудиоплеера, загрузка счетчиков просмотров и интерактивные элементы.

## ⚙️ Как кастомизировать под себя

Если вы взяли этот шаблон за основу своего био, вам нужно изменить следующие файлы:
* `index.html` — замените текст, ссылки на Discord, цены в прайс-листе и описание на свои.
* `/assets/` (или папка с музыкой) — замените аудиофайл на свой любимый трек.
* `README.md` — не забудьте обновить описание проекта и ссылку на ваш GitHub Pages!
